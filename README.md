# collection-maintable2
# 1. Install Git if you haven't: https://git-scm.com

# 2. Create a folder and put your HTML file in it, then open a terminal there

# 3. Initialize a git repo
git init

# 4. Add your file
git add techpack_manager_v2.html

# 5. Commit it
git commit -m "Add tech pack manager"

# 6. Connect to your GitHub repo (replace the URL with yours)
git remote add origin https://github.com/YOUR_USERNAME/techpack-manager.git

# 7. Push it up
git branch -M main
git push -u origin main
